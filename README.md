# Veeam Backup & Replication Checks

Reviews the deployment and configuration state of Veeam Backup & Replication

## Install and run

```powershell
Install-MtPack soulemike/maester-pack-veeam-backup-replication
Connect-Maester
Invoke-Maester -Pack VBR
```

This is a [Maester Pack](https://maester.dev/docs/packs). Its page is [packs.maester.cloud/p/vbr](https://packs.maester.cloud/p/vbr).
